# About
Roomski is a simple room made by someone doing cad for the first time! It features
1. Four Walls
2. A Floor and a Ceiling
3. Wall Decor-inbuilt shelves, protruding shelves,wall board and wall pennants
4. A bunk bed w/ a ladder
5. A desk and chair, complete with a desktop setup!
6. A side table+lamp
